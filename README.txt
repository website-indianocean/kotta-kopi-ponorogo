KOTTA KOPI — BOLD URBAN EDITORIAL / PREMIUM V2
================================================

A responsive, multi-page, unofficial design concept built with plain HTML, CSS and JavaScript.
Open index.html, or upload the files from the ZIP root to a static hosting provider.

WHAT IS NEW IN V2
- All-page visual refresh: premium.css extends the original reusable design system.
- Continuous LEFT-moving testimonials-style editorial carousel on Home and Guest Experiences.
- The duplicated carousel group is decorative/aria-hidden; reduced-motion visitors see a swipeable static row.
- Page entrance enhancements, image treatment, navigation, footer, menu, gallery and responsive refinements.

IMPORTANT CONTENT NOTE
- Testimonial cards are clearly marked illustrative sample copy; they are NOT authentic user reviews or ratings.
- Replace with verified, approved testimonials before using as a client production site.
- Menu entries, photography and business content remain conceptual; validate with Kotta Kopi management.
- No guessed WhatsApp contact, address, hours, prices or booking availability are provided.

FILES
- index.html: homepage
- menu.html, gallery.html, spaces.html, about.html, visit.html, reviews.html and support pages
- site.css: base stylesheet
- premium.css: premium visual system and marquee
- main.js: navigation, reveal animation, menu, dialog and gallery behavior
- static WebP and PNG assets

No build tools or external JS libraries are required. Google Fonts are loaded from Google.
